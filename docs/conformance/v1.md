# Conformance vectors v1

The `vectors/v1` directory contains deterministic, synthetic data for independent implementations.
[`vectors/v1/manifest.json`](../../vectors/v1/manifest.json) binds each normative schema, vector,
and development public-root file by SHA-256.

Positive vectors demonstrate exact canonical bytes, non-normalized Unicode preservation, and round
trips. Malicious negative vectors
cover unknown fields, wrong artifact digests, incompatible versions, undeclared permissions,
dependency cycles, absent SBOM/license data, publisher mismatch, noncanonical JSON/base64, every
signed digest mutation, invalid signatures, pack/catalog role confusion, catalog-byte tamper,
unknown/development/revoked roots, successor authority expansion, unbounded rotation, rollback to a
revoked artifact after successful historical verification, unsafe pack paths, optional or
contradictory permissions, isolation mismatch, overlapping platform ranges, schema-bound
divergence, and oversized versions/JSON integers.

Generators are deterministic and checked with:

```bash
uv run --frozen --extra dev python tools/build_schema_types.py --check
uv run --frozen --extra dev python tools/build_pack_vectors.py --check
uv run --frozen --extra dev python tools/build_vector_manifest.py --check
```

A passing vector suite proves only conformance to the named contract bytes. It does not qualify a
parser, format, operating system, product workflow, release, or support boundary.
