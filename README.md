# contracts

Language-neutral evidence, review, and pack contracts with conformance vectors.

This repository currently contains its governed foundation. Implementation and releases arrive
through reviewed, repository-local work. Until a release says otherwise, this repository makes no
product-support or availability claim.

## Start here

- Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change.
- Report vulnerabilities through [SECURITY.md](SECURITY.md), never a public Issue.
- Run `./scripts/check` before opening or updating a pull request.
- See [SUPPORT.md](SUPPORT.md) for public questions and support boundaries.

## Scope

`sangrep/contracts` owns only the Contracts component described here. It communicates
with other components through released artifacts and public contracts, not source-tree imports.
